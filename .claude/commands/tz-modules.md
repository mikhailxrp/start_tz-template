Заполни подразделы раздела 8, указанные в аргументе: $ARGUMENTS

Прочитай перед началом:

- `reference/prompt-tz-agent.md` — особенно п. 4.3 формат требования
- `01-tz/tz.md` разделы 4, 5, 6, 7 — язык и сценарии
- `01-tz/decisions.md`
- `00-input/brief.md` — пункты, указанные в `01-tz/coverage.md`
  для этих подразделов

Правила:

- Полный формат требования, без сокращений. Каждое: ID с маркером,
  приоритет, очередь, роль, источник, требование, правила,
  критерии приёмки, связи.
- Каждое требование покрывает шаг сценария из раздела 7 или
  бизнес-правило из раздела 9.
- Матричные правила не разбивай на отдельные требования — это `BR-NNN`.
- Термины только из глоссария.

После записи ОБЯЗАТЕЛЬНО:

1. Запусти `python tools\check_tz.py 01-tz\tz.md`
2. Исправь все ошибки уровня ERROR
3. Выведи отчёт:
   - количество требований и их ID по каждому подразделу
   - распределение по приоритетам MUST/SHOULD/COULD
   - сколько с маркером /Б, сколько с /Р
   - какие пункты брифа остались непокрытыми
   - что решил сам и почем
