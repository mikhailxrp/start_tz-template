description: Этап 3. Сценарии использования с ошибочными ветками (раздел 7)
---

Прочитай:

- `reference/prompt-tz-agent.md`
- `01-tz/tz.md` разделы 4, 5, 6 — язык документа
- `01-tz/decisions.md`
- `00-input/brief.md` пункты 4.1-4.6, 5.1-5.3

Заполни раздел 7 в `01-tz/tz.md`.

Формат: цель → шаги → альтернативные ветки → ошибочные ветки.

Обязательно разбери применимые ошибочные ветки из чек-листа раздела 7
шаблона. Сценарий без разобранных ошибочных веток не считается готовым —
именно эти ветки съедают сроки на этапе разработки.

Используй только термины из глоссария раздела 4. Синонимы запрещены.

После записи выведи: список сценариев с ID, какие ошибочные ветки
разобраны, какие признаны неприменимыми и почему.
